เลขที่ —
🎯 ออฟฟิศแจ้งเสีย 4 เครื่องพร้อมกัน — วงเครือข่ายที่ถูกต้องคือ 192.168.1.x · ประตูออกเน็ต (Gateway) = 192.168.1.254
👷 หน้าที่ช่าง: ไล่ตามบันได 4 ขั้น (สาย → IP → ping → ด่านกั้น) แล้วจดใบสั่งซ่อมลงสมุด
🧭 ลำดับที่ต้องทำ — ① ใส่เลขที่ก่อน → ② แตะเครื่องที่แจ้งเสียเพื่อ ตรวจสภาพ → ③ พิมพ์ ping ทดสอบก่อน–หลังทุกครั้ง → ④ ซ่อมจบเคสไหน เดินมาโชว์จอครูเคสนั้นทันที
เคส A · บัญชี (.40)เข้าเน็ตไม่ได้ เครื่องอื่นปกติ
เคส B · เครื่องใหม่ (.70)คุยในแผนกได้ แต่ออกเน็ตไม่ได้
เคส C · สต๊อกเน็ตติดๆ หลุดๆ เตือนเรื่อง IP ซ้ำ
เคส D · พิมพ์กลาง (.100)ping เจอ แต่สั่งพิมพ์ไม่ได้
📐 ผังที่ถูกต้องของออฟฟิศนี้
เน็ตผู้ให้บริการ (ISP) → เราเตอร์ (192.168.1.254) → สวิตช์ → แตกออกไปทุกเครื่อง
สวิตช์ต้องมีสายไปครบ 5 เส้น: โต๊ะเธอ · บัญชี(.40) · สต๊อก · เครื่องใหม่(.70) · พิมพ์กลาง(.100)
⚠️ ทุกเครื่องต้องมี IP ไม่ซ้ำกัน + ตั้ง Gateway = 192.168.1.254 ให้ครบทุกเครื่อง
💻 Terminal
เริ่มจาก ipconfig ดูค่าของเครื่องก่อน แล้วค่อย ping — คำสั่ง ping ต้องพิมพ์เอง
>
🔴 วงแดง = เครื่องที่แจ้งเสีย · 🛡️ โล่ = Firewall บล็อกอยู่ · ⚠️ = IP ผิดปกติ
💡 บันได 4 ขั้น: ① สาย/พอร์ต ② IP–Subnet–Gateway ③ ping ในวง แล้วข้ามวง ④ Firewall
