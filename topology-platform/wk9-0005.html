เลขที่ —
🎯 โจทย์: เดินระบบเน็ตร้านกาแฟ 2 ชั้น
ชั้น 1 — POS คิดเงิน (PC) ×2 + Server เก็บยอดขาย ×1 เสียบสายเข้า Switch · Switch ต่อขึ้น Router (ประตูออกเน็ต)
ชั้น 2 — AP กระจาย Wi-Fi (ต่อสายลงมาเข้า Switch) + มือถือลูกค้า (ใช้ PC แทน) ต่อไร้สายเข้า AP
☕ ในแอปไม่มี Modem — ถือว่า Router ตัวนี้คือกล่องรวมร่าง 3-in-1 (Modem+Router+ไฟร์วอลล์) แบบร้านจริง
1 ใส่ชื่อ+เลขที่
2 วางครบ: Router 1 · Switch 1 · PC 3 (POS 2 + มือถือลูกค้า 1) · Server 1 · AP 1
3 เชื่อมถูกโครง: POS+Server+AP → Switch · Switch → Router · มือถือ → AP (ไร้สาย)
4 ตั้ง IP POS = 192.168.1.(เลขที่เธอ) + ping ถึง Server สำเร็จ
5 ✂️ ตัดสายเข้า Switch แล้ว ping ใหม่ — เหลือกี่เครื่องคุยกันได้?

⚙️ ตั้งค่า IP
