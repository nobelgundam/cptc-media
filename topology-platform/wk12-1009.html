เลขที่ —
🎯 เช้าวันจันทร์ ออฟฟิศโทรตามด่วน — 3 เครื่องใช้ไม่ได้พร้อมกัน อาการไม่เหมือนกัน
เครื่องพิมพ์ .100 · เครื่องสต๊อก .120 · เครื่องหัวหน้า .60 · เครื่องบัญชี .50 (ปกติดี)
🩺 ภารกิจหมอ: ping ดูอาการ → หาสาเหตุจริง → แก้ให้ครบ 3 เครื่อง
🩺 ลำดับตรวจแบบช่าง — ① ตาดู (สายหลุด/ไฟพอร์ต) → ② ดูป้ายชื่อ (IP ถูกวงไหม ซ้ำไหม) → ③ เคาะประตู (ping) → ④ ดูด่านกั้น (Firewall)
1 ใส่เลขที่ (ตั้ง IP โต๊ะเธอ)
2 🔴 ลองตั้ง IP ให้ซ้ำกับเครื่องบัญชี .50 → ระบบฟ้องว่าอะไร (จดสมุด!)
3 🖨️ เคสเครื่องพิมพ์ .100 — ping ไม่เจอ → ตรวจสาย → ต่อสายให้ → ping ผ่าน
4 📦 เคสเครื่องสต๊อก .120 — ping ไม่เจอ → ดู IP ให้ดี → แก้ให้ถูกวง → ping ผ่าน
5 🛡️ เคสเครื่องหัวหน้า .60 — ping ไม่เจอ → เจอด่านกั้น → เปิดอนุญาต → ping ผ่าน
📝 จดสมุดทุกเคส: อาการ (ข้อความที่เห็นก่อนแก้) → สาเหตุจริง → วิธีแก้
💡 ข้อความต่างกัน = โรคต่างกัน — "สายยังไม่เชื่อมถึงกัน" ≠ "คนละวง" ≠ "Firewall บล็อก"

🔌 โหมดต่อสาย = แตะอุปกรณ์ตัวแรก แล้วแตะตัวที่สอง เพื่อเชื่อมสาย UTP · ⚙️ โหมดตั้งค่า = แตะเครื่องเพื่อแก้ IP / Firewall
💡 3 อาการที่ต้องแยกให้ออก: สายยังไม่ถึงกัน (สื่อกลาง) · คนละวง (IP ผิด) · Firewall บล็อก (ด่านในเครื่อง)
