🎮 ภารกิจ: เปิดร้านเกม เชื่อมเน็ตให้ลูกค้าเล่นได้
วางเอง ตามลำดับจริง: ผู้ให้บริการเน็ต (ISP) → เราเตอร์ → สวิตช์ → คอมลูกค้า · ต่อให้ถูก → ตั้ง IP + Gateway → ทดสอบ ping / tracert ทั้งในร้าน + ออกเน็ต
1 ใส่ชื่อ-เลขที่ + วางครบ: ISP · เราเตอร์ · สวิตช์ · คอม 2 เครื่อง
2 เชื่อมถูกลำดับ: ISP→เราเตอร์→สวิตช์→คอม (ISP ต่อคอม/สวิตช์ตรงไม่ได้)
3 ตั้ง IP คอม (เลขท้าย = เลขที่เธอ) + ตั้ง Gateway = IP เราเตอร์
4 📶 ping คอมเพื่อนในร้าน สำเร็จ (วงเดียวกัน)
5 🌐 ping หรือ tracert ออกเน็ต (8.8.8.8 / google.com) สำเร็จ

⚙️ ตั้งค่า IP

กรอกเลข IP 4 ชุด (0–255) · ห้ามลงท้าย .0 / .255 · ห้ามซ้ำเครื่องอื่นในวงเดียวกัน · เลขท้ายแนะนำ = เลขที่ของเธอ (กันลอก)

🔒 ตั้งรหัสผ่าน Wi-Fi ให้อุปกรณ์นี้ · ต้องเป็น "รหัสแข็งแรง" ครบ 5 ข้อ · เว้นว่าง = เปิด (ใครก็เกาะได้ เน็ตช้า ไม่ปลอดภัย)
