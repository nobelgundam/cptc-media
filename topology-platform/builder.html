🛠️ เริ่มสร้างเครือข่าย

ใส่เลขที่ของตัวเองก่อน — งานที่ทำจะถูกเก็บแยกตามเลขที่ ถ้าใช้มือถือเครื่องเดียวกันหลายคน งานจะไม่ปนกัน

🔄 เปลี่ยนเลขที่ = สลับไปดูงานของเลขที่นั้น · งานของเลขที่เดิมไม่หาย ระบบเก็บแยกไว้ให้ กลับมาใส่เลขเดิมก็เจอเหมือนเดิม

⚙️ ตั้งค่า IP

a-z 0-9 และ - · ขึ้นต้นด้วยตัวอักษร · ไม่เกิน 15 ตัว · ห้ามเว้นวรรค

เครื่องนี้จะขอ IP เองจาก DHCP Server · กด "บันทึก" = ขอทันที · เลขที่ได้ดูใน Terminal

กรอกเลข IP 4 ชุด (0–255) · ห้ามลงท้าย .0 / .255 · ห้ามซ้ำเครื่องอื่นในวงเดียวกัน

นี่คือชื่อเว็บใน DNS (ไม่ใช่ชื่ออุปกรณ์ด้านบน) เช่น shop.local — เครื่องอื่นพิมพ์ชื่อนี้แทนเลข IP ได้

🔒 ใส่รหัส Wi-Fi

อุปกรณ์นี้ตั้งรหัส Wi-Fi ไว้ — ใส่รหัสให้ถูกเพื่อเชื่อมไร้สาย

🛡️ ตั้งค่า Firewall

ทุกเครื่อง Windows มี "รปภ.เฝ้าประตู" = Firewall · ค่าเริ่มต้น = บล็อกคนแปลกหน้า (ping/แชร์ไม่ได้) · เปิด "Allow File and Printer Sharing" ให้เพื่อนในวงเข้าถึง/พิมพ์ได้

💾 เซฟ / เปิดผัง

มือถือเครื่องเดิม + เปิดทางเดิม = ผังยังอยู่ ไม่ต้องกดอะไร · ท้ายคาบกด ⬇️ เซฟเป็นไฟล์ เก็บไว้ เผื่อเปลี่ยนเครื่อง ล้างเบราว์เซอร์ หรือ iPhone ลบข้อมูลเว็บที่ไม่ได้เปิดนาน
