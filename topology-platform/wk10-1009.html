เลขที่ —
🎯 ออฟฟิศต่อสายครบแล้ว วงเดียวกันหมด (192.168.1.x) — แต่ ping เครื่องพิมพ์กลาง (.100) ไม่เจอ!
โต๊ะเธอ = IP ลงท้ายเลขที่ตัวเอง · พิมพ์กลาง = .100 · โต๊ะ2 = .101 · โต๊ะ3 = .102 · โต๊ะ4 = .103
🕵️ ภารกิจช่าง: หาว่าทำไม "สายครบ วงเดียวกัน" แต่ยังส่งไม่ถึง แล้วแก้ให้แชร์/พิมพ์ได้
1 ใส่เลขที่ (ตั้ง IP โต๊ะเธอ)
2 🕵️ ping พิมพ์กลาง (192.168.1.100) → เจอ Request timed out (จดสมุด!)
3 🛡️ เปิด Firewall เครื่องพิมพ์ (Allow Sharing) แล้ว ping .100 สำเร็จ → พิมพ์ออก!
📝 จดสมุด ตอนที่ 3 (เติมคำในช่องว่าง):
1) อาการ: ping เครื่องพิมพ์ขึ้นว่า ทั้งที่สายครบ วงเดียวกัน
2) สาเหตุ: เครื่องพิมพ์มี (รปภ.เฝ้าเครื่อง) บล็อกไว้
3) วิธีแก้: เข้าไปเปิดสวิตช์ (อนุญาตแชร์ไฟล์+เครื่องพิมพ์)
💻 Terminal
แตะเครื่องบนกระดานเพื่อตั้ง Firewall · พิมพ์ ping 192.168.1.100 ทดสอบส่งไปเครื่องพิมพ์กลาง
>
🛡️ โล่ = Firewall กำลังบล็อก (ping ไม่เข้า) · 🔓 = เปิด Allow Sharing แล้ว
💡 ช่างต้อง: ping ดูก่อน → เจอ timed out → แตะเครื่องนั้น เปิด Firewall → ping ใหม่ให้ทะลุ (โยงข้อสอบข้อ 36: ไฟติด ≠ ใช้ได้)
← สื่อวิชานี้

👷 ช่างประจำออฟฟิศ

ใส่เลขที่ตัวเอง → IP โต๊ะเธอจะลงท้ายด้วยเลขนี้ (กันลอก ครูตรวจสด)

🛡️ ตั้งค่า Firewall

ทุกเครื่อง Windows มี "รปภ.เฝ้าประตู" = Firewall · ค่าเดิม = ไม่รับแขกแปลกหน้า (ping/แชร์ไม่ได้) · เปิด "Allow File and Printer Sharing" ให้เพื่อนในวงเดียวกันเข้าถึง/พิมพ์ได้
