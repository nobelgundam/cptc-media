ปิดช่องโหว่ออฟฟิศ (สัปดาห์ 12 · 31909-0005 · ใบงานที่ 10)

อุปกรณ์ 0 · สาย 0
แตะอุปกรณ์บนกระดานเพื่อตั้งค่าความปลอดภัย · พิมพ์คำสั่งใน Terminal ล่างจอ
เลขที่ —
🎯 ออฟฟิศต่อสายครบแล้ว วงเดียวกันหมด (192.168.1.x) — เจ้าของบ่น 3 เรื่อง:
① สั่งพิมพ์ไปเครื่องพิมพ์กลาง (.100) ไม่ได้ · ② คนนอกแอบเกาะ Wi-Fi เน็ตอืด · ③ เครื่องพนักงาน (.60) เด้งโฆษณา ช้า
👷 ภารกิจช่าง: ไล่ปิดทีละช่อง แล้วจดอาการ–สาเหตุ–วิธีแก้ลงสมุด
🧭 ทำตามลำดับนี้ (ห้ามข้าม) — ขั้น 1 ใส่เลขที่ → ขั้น 2 พิมพ์ ping 192.168.1.100 ดูอาการก่อน → ขั้น 3 แตะ พิมพ์กลาง เปิด Allow Sharing แล้ว ping ใหม่ → ขั้น 4 แตะ Wi-Fi ออฟฟิศ ตั้งรหัสให้ครบ 5 ข้อเขียว → ขั้น 5 แตะ เครื่องพนักงาน ลดสิทธิ์เป็น User + สแกนไวรัส
1 ใส่เลขที่ (ตั้ง IP โต๊ะเธอ)
2 🕵️ ping พิมพ์กลาง (192.168.1.100) → เจอ Request timed out (จดอาการ!)
3 🔓 เปิด Allow Sharing ที่พิมพ์กลาง → ping ผ่าน → พิมพ์ออก
4 🔒 ตั้งรหัส Wi-Fi ออฟฟิศให้แข็งแรงครบ 5 ข้อ → คนนอกหลุด เน็ตเร็วขึ้น
5 👤 เครื่องพนักงาน: ลดสิทธิ์เป็น User + อัปเดต/สแกนไวรัส → โฆษณาหาย
📝 จดสมุด ภารกิจที่ 2 (เติมคำในช่องว่าง):
1) อาการ: ping เครื่องพิมพ์ขึ้นว่า ทั้งที่สายครบ วงเดียวกัน
2) สาเหตุ: เครื่องพิมพ์มี (รปภ.เฝ้าประตูเครื่อง) บล็อกอยู่
3) วิธีแก้: เข้าไปเปิด แล้ว ping ใหม่
4) Wi-Fi ไม่มีรหัส = คนนอกเกาะ → ความเร็วเหลือ Mbps · ตั้งรหัสแล้วเหลือ Mbps
5) พนักงานควรใช้สิทธิ์ เพราะ
💻 Terminal
ขั้นแรก: พิมพ์ ping 192.168.1.100 ดูว่าส่งถึงเครื่องพิมพ์กลางไหม
>
🛡️ โล่ = Firewall บล็อกอยู่ · 🔓 = เปิด Allow Sharing แล้ว · 🔒 = Wi-Fi มีรหัสแล้ว
💡 ความปลอดภัยมี 3 ชั้นที่ช่างต้องดู: ชั้นเครื่อง (Firewall + สิทธิ์ผู้ใช้ + แอนตี้ไวรัส) · ชั้นเครือข่าย (รหัส Wi-Fi) · ชั้นคน (ไม่บอกรหัสใคร)
← สื่อวิชานี้

👷 ช่างดูแลความปลอดภัยประจำออฟฟิศ

ใส่เลขที่ตัวเอง → IP โต๊ะเธอจะลงท้ายด้วยเลขนี้ (กันลอก ครูตรวจสด)

🛡️ ตั้งค่า Firewall

ทุกเครื่องมี "รปภ.เฝ้าประตู" = Firewall · ค่าเดิม = ไม่รับแขกแปลกหน้า (ping/แชร์/พิมพ์ไม่ได้) · เปิด "Allow File and Printer Sharing" ให้เพื่อนในวงเดียวกันใช้งานได้

🔒 ตั้งรหัส Wi-Fi ออฟฟิศ (WPA2)

Wi-Fi ที่ไม่ตั้งรหัส = ใครเดินผ่านก็เกาะได้ เน็ตถูกแบ่งจนอืด · ตั้งรหัสให้ครบ 5 ข้อถึงจะแข็งแรงพอ

  • ☐ มีตัวเลข 0-9
  • ☐ มีสัญลักษณ์ ! @ # $
