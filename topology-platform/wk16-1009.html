🏢 เป้าหมาย: ทำให้ ทุกแผนกสั่งพิมพ์ได้ + แผนกช่างออกเน็ตได้ · สายต่อครบแล้ว ปัญหาอยู่ที่ค่าที่ตั้งไว้
🧭 ลำดับที่ต้องทำ — ① ใส่เลขที่ → ② แตะเครื่องอ่านค่า → ③ แก้ → ④ ยิง ping จากเครื่องนั้นให้ผ่านเองกับตา (แก้เฉย ๆ ยังไม่นับจบ) → ⑤ จดอาการ + สาเหตุ + วิธีแก้ ลงสมุด
🔢 เลขเครื่องที่สำนักงานนี้กำหนดให้ช่าง (คิดเองจากเลขที่ของเธอ)
แผนกขาย = ชุดท้าย เลขที่ + 40 · แผนกช่าง = ชุดท้าย เลขที่ + 70 · เลขที่ของเธอ —
3 ชุดแรกใช้ของออฟฟิศ ดูจากเครื่องแผนกบัญชีที่ใช้งานได้อยู่แล้ว · เครื่องพิมพ์กลาง = 192.168.1.200
📋 อาการที่ลูกค้าแจ้ง 3 เคส (0/3) — แตะเพื่อย่อ/ขยาย
เคส A · แผนกขายสั่งพิมพ์ไม่ได้ ทั้งที่สายต่อครบ ไฟติดเขียว
ทดสอบเคสนี้ด้วยการ ping แผนกบัญชี ก่อน (เครื่องพิมพ์ยังมีปัญหาของเคส B ค้างอยู่)
เคส B · เครื่องพิมพ์กลางทุกแผนกสั่งพิมพ์ไม่ได้เลย แม้แผนกที่วงถูกแล้ว
เคส C · แผนกช่างเปิดเว็บไม่ได้ — เครื่องนี้ยังไม่ได้ตั้งค่าอะไรเลย
