เลขที่ —
🎮 เปิดร้านวันแรก ลูกค้าบ่นพร้อมกันหลายเรื่อง — 6 เครื่องต่อสวิตช์ตัวเดียว ออกเราเตอร์ 192.168.1.1 วง 192.168.1.x
👷 หน้าที่ช่าง: แยกให้ออกว่าปัญหาอยู่ที่ เครื่อง หรืออยู่ที่ เส้นทางเชื่อมต่อ แล้วซ่อมให้ครบ 3 เคส
🧭 ลำดับที่ต้องทำ — ① ใส่เลขที่ก่อน → ② แตะเครื่องที่บ่นเพื่อ ตรวจสภาพ → ③ พิมพ์ ipconfig กับ ping ก่อน–หลังทุกครั้ง → ④ ซ่อมจบเคสไหน จดลงสมุดเคสนั้นทันที (สาเหตุ + วิธีแก้ อย่างละบรรทัด)
🔢 เลข IP ที่ต้องใช้ซ่อม (คิดจากเลขที่ของเธอ — ห้ามใช้ของเพื่อน)
เครื่อง 5 ตั้งใหม่เป็น — · เครื่อง 6 เปลี่ยนเป็น — · Gateway ทั้งคู่ = 192.168.1.1
เคส A · เครื่อง 4เข้าเกมออนไลน์ไม่ได้ แต่เปิดเว็บของร้านในเครื่อง 1 ได้
เคส B · เครื่อง 5เข้าอะไรไม่ได้เลย ไฟช่อง LAN ไม่ติด · IP ขึ้น 169.254.8.77
เคส C · เครื่อง 6เดี๋ยวได้เดี๋ยวหลุด — มี 2 ปัญหาซ้อนกัน เจอทั้งคู่ถึงจะจบ
📐 หลักของระบบที่ใช้งานได้
① พอร์ตมีสาย ไฟช่อง LAN ติด
② ทุกเครื่องมี IP ไม่ซ้ำกัน ในวงเดียวกัน
③ เครื่องที่ต้องออกเน็ตมี Gateway
เทียบหลัก 3 ข้อนี้กับค่าที่อ่านได้จากหน้าเครื่อง แล้วหาว่าข้อไหนของเครื่องนี้ที่ไม่ตรง
💻 Terminal
เริ่มจาก ipconfig ดูค่าเครื่องก่อน แล้วค่อย ping — ping ในวงใช้ IP เครื่องอื่น · ออกเน็ตใช้ ping 8.8.8.8

🔴 วงแดง = เครื่องที่ลูกค้าบ่น · ⚠️ = ค่าผิดปกติ · เครื่องที่ไม่มีสาย = ไฟช่อง LAN ไม่ติด
💡 โพยช่าง: IP ขึ้นต้น 169.254. = ขอ IP ไม่ได้เลย (สาย/พอร์ต) · ไม่มี Gateway = ในวงคุยได้ ออกเน็ตไม่ได้ · IP ซ้ำ = สลับกันหลุด
